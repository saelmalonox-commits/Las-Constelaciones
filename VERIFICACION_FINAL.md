# Verificación · Las Constelaciones V3.0.0

Comandos de verificación del repositorio:

```bash
npm test
npm run check
```

La suite contiene **31 pruebas automatizadas** y cubre el motor de comparación, gestos y geometría del campo, renderizado INICIO/MOVIMIENTOS/AHORA, migración de sesiones, cuatro modos de experiencia, seis corrientes doctrinales, frases sistémicas, cierre, manifest PWA y service worker compatible con GitHub Pages.

La aplicación es estática y no requiere proceso de build para publicarse.
